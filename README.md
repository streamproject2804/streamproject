# SteamGuard Boiler Management

Responsive MVP dashboard for boiler operations, manual reading checks, safety checklists, maintenance, incidents, documents, reports, and administration.

## Run locally

```bash
npm install
npm run dev
```

## Production build

```bash
npm run build
```

The current MVP uses interactive demonstration data in the browser. Connect Supabase before production use to provide authentication, persistent records, file storage, and role-based database security.

SteamGuard supports operational record management. It does not replace certified boiler controls, alarms, safety interlocks, PLC systems, safety valves, emergency shutdown systems, manufacturer instructions, or approved operating procedures.
