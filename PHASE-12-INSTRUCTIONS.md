# SteamGuard Phase 12 — Functional Admin Panel

## Included modules

- Users & Roles: change roles, approve/reject accounts, activate/block access.
- Boilers: add, edit and delete boiler registrations.
- Operational Limits: edit minimum and maximum reading limits.
- Checklist: add, edit and remove safety checklist definitions.
- Audit Trail: review recent administrator changes.

## Installation

1. Upload all Phase 12 project files to GitHub while preserving the folder structure.
2. Open Supabase **SQL Editor**.
3. Open `supabase/phase-12-functional-admin.sql`, copy its complete contents, and run it once.
4. Redeploy the latest GitHub commit in Vercel.
5. Sign out, refresh the website, and sign in using `muthuramanajith28@gmail.com`.
6. Open Admin Panel and test every tab.

Do not type the SQL filename into Supabase SQL Editor. Copy and run the SQL content inside the file.
